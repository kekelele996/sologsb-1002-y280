# 学术论文协作审阅台

面向作者、审稿人与编辑三类角色的论文协作审阅前端。审阅台与期刊稿库各存一份正文，批注、讨论、建议、版本和冲突处理数据均保存在浏览器本地。

## 功能

- 三个独立工作区：
  - 作者可直接修改正文，逐条接受或拒绝审稿人的修改建议。
  - 审稿人可引用原文、添加段落批注、提出修改建议并回复讨论。
  - 编辑可合并重复意见、锁定段落、在稿库把段落定稿并出新版本、比较两个版本。
- 审阅台 ↔ 期刊稿库双向对接：
  - 两边先后动过同一段时，已定稿的以稿库为准，未定稿的以审阅台为准。
  - 批注与建议并集合并，作者刚写下的内容不会被抹掉；稿库已定稿段落受写保护，审阅台的改动顶不回去。
  - 对接失败后改动留在审阅台等待重试，稿库已定稿内容照旧可查（展示最近快照），重试只补没上去的稿库一侧。
  - 头部「断连」开关可模拟稿库离线，「稿库」抽屉可查看稿库正文、期刊版本、待补推队列与对接日志。
- 每段正文与每条意见都带归属标记（审阅台 / 稿库）；旧版本地数据升级时自动按两边补录归属。
- 侧边目录、段落高亮、批注过滤、修订模式与版本差异表。
- `J` / `K` 在段落之间导航，`T` 切换修订模式，编辑角色可用 `L` 锁定或解锁段落；`Ctrl/⌘ + Z` 撤销，`Ctrl/⌘ + Y` 或 `Shift + Z` 重做。
- 完整撤销重做、手动保存和浏览器未保存提醒。
- 草稿、待发队列与稿库快照分别写入 `localStorage`，刷新或断网后仍可继续。
- 内置模拟接口。点击“模拟冲突”会让远端协作者修改当前段落，并展示本页版本与远端版本，可选择保留任一方。
- 页面包含完整的示例论文、批注、回复、重复意见和两个历史版本。

## 技术栈

- React 19
- Vite + TypeScript
- Zustand
- Ant Design
- localStorage + 浏览器内模拟接口

## 本地开发

```bash
npm install
npm run dev
```

开发端口由 Vite 决定，源码不硬编码宿主端口。

## 生产构建

```bash
npm install
npm run build
npm run preview
```

## Docker

```bash
docker build -t sologsb-1002 .
docker run --rm -p 10002:80 sologsb-1002
```

容器内的 nginx 监听 `80`，访问 `http://localhost:10002`。
